# Working notes

Dated, append-only session notes: one Markdown file per session or topic, named
`YYYY-MM-DD-topic.md`.

Notes hold context, observations, and open questions. They are not the system of record:

- Decisions graduate to `docs/decisions/` as ADRs.
- Shipped changes get an entry in `CHANGELOG.md`.
- Repo-wide rules land in `CLAUDE.md` Project Notes.
