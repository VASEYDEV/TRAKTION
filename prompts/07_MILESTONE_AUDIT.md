# Prompt: TRAKTION Milestone Audit

Perform an evidence-driven milestone audit using the roadmap, merged changes, acceptance criteria, golden/evaluation results, performance results, and open defects.

## Required report
1. Completed capabilities
2. Missing or partial capabilities
3. Golden-test status
4. False-safe findings
5. Performance/memory concerns
6. Privacy/security changes
7. Architecture drift from ADRs
8. Technical debt blocking the next milestone
9. Recommendation: pass / pass with follow-up / fail milestone

Do not infer completion from issue labels or agent summaries. Verify from code, tests, and artifacts.
