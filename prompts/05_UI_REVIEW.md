# Prompt: Independent UI Review

Review the TRAKTION UI change against the task, product spec, and editing model.

## Focus
- Can users tell source content from reconstructed output?
- Are uncertain joints discoverable without clutter?
- Is manual alignment precise and reversible?
- Can a user accidentally delete or overwrite originals?
- Do undo/redo semantics match visible actions?
- Are zoom, loupe, difference, and ghost views usable at the seam?
- Are disabled/unavailable features represented honestly?
- Is the flow accessible with Dynamic Type, VoiceOver, and adequate hit targets?
- Does the UI avoid unnecessary model/provider concepts?

Reproduce the documented flow and report issues using the review template.
