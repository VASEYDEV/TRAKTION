# Real-world fixtures

Real captures (screenshots, recordings) are potentially sensitive and stay out
of version control (docs/adr/ADR-010-private-fixtures.md).

- Put private captures under `Private/` or `Local/` — both are gitignored.
- Nothing in CI may depend on files in this directory.
- Committed tests use `Tests/SyntheticFixtures/` (deterministic, generated by
  FixtureForge) instead.
